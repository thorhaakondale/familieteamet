# Familieteamet — familiens oppgavetavle

Statisk PWA (GitHub Pages) + Firebase Realtime Database for familiens haker.

- `index.html` — appen (ingen byggesteg)
- `data/oppgaver.json` — oppgavebanken (agentstyrt: Bjørn/Liv oppdaterer via GitHub API)
- `data/innstillinger.json` — ukemål-prosent, belønningstrappa, dagsplaner
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — «Legg til på Hjem-skjerm»

Familiekoden ligger IKKE i repoet. Den gis i lenka én gang (`?k=KODE`) og huskes av enheten.
